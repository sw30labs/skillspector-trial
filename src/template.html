    ABOUT SKILLSPECTOR

    Static security and quality analysis for Claude Agent Skills.

    What it does

    Drag a skill in — a folder, a .zip, or a .skill bundle — and the engine grades it A–F against 21 rules: ten security (SEC-001…010) and eleven quality (QUA-001…011). Rules key on the shape of an attack, not on mere capability: a newsletter skill that sends mail over SMTP with an env-var password grades A with its capabilities listed, while one that reads ~/.aws/credentials and POSTs it to a webhook grades F.

    The AI Analyst

    The optional bridge (node server.mjs) puts a local OMLX model behind three review passes: triage reads SKILL.md for intent and undeclared behaviour, adjudicate rules each finding confirmed / false-positive / needs-review, and verdict issues an install recommendation. Same provider contract as contingency-atlas and book-buddy-2026 — loopback only, nothing leaves the machine.

    Stack

    scan engine · zero-dependency JavaScript
    deck UI · single self-contained HTML file
    bridge · node stdlib http, loopback-bound
    model · OMLX / OpenAI-compatible, non-streaming

    Run it

    open index.html # offline, no server
    node server.mjs # + AI analyst on :8787
    node build.mjs # rebuild index.html
    node tests/run-tests.mjs # engine suite
    node tests/run-bridge-tests.mjs # bridge suite
    node tests/run-e2e.mjs # deck in a real browser

    Privacy

    The scan itself never leaves the browser — no network calls, no telemetry, works straight off file://. The AI Analyst is opt-in and talks only to a loopback OMLX endpoint; a non-loopback endpoint is refused unless you set SKILLSPECTOR_ALLOW_REMOTE_LLM=1 yourself.
